Option B: Run End-to-End Locally (Docker + Swagger / cURL)
To test the live REST APIs with the actual PostgreSQL schema (all Flyway migrations auto-running) and Redis:

Step 1: Start PostgreSQL & Redis Containers
From d:\MyProject_2025\IYS_Managment_System\iys-backend:

powershell


docker-compose up -d
Verify the containers are healthy:

powershell


docker ps
(You will see iys_postgres on port 5432 and iys_redis on port 6379.)

Step 2: Start the Spring Boot Backend
powershell


mvn spring-boot:run -Dspring-boot.run.profiles=dev
When it starts, Flyway will automatically execute migrations V1.0 through V10.3, creating all tables and default roles/permissions.

Step 3: Test via Swagger UI
Open your browser and go to: http://localhost:8080/swagger-ui.html
You will see all endpoints grouped by:
Authentication: /api/v1/auth/*
Centres: /api/v1/centres/*
Users: /api/v1/users/*
Devotees: /api/v1/devotees/*
Step 4: Step-by-Step API Testing Flow (cURL or Postman)
You can copy and run these PowerShell / cURL commands in order:

1. First, seed or get a Centre ID
When running with blank data, log into PostgreSQL or create a centre.

To create a centre directly via psql:

powershell


docker exec -it iys_postgres psql -U iys_user -d iys_db -c "INSERT INTO centres (id, name, short_code, city, country, is_active) VALUES ('11111111-1111-1111-1111-111111111111', 'ISKCON Pune', 'PUN', 'Pune', 'India', true) ON CONFLICT DO NOTHING;"
2. Register a new user
powershell


curl -X POST http://localhost:8080/api/v1/auth/register `
  -H "Content-Type: application/json" `
  -d '{
    "email": "devotee@iskcon.org",
    "password": "Password@123",
    "legalName": "Rahul Sharma",
    "centreId": "11111111-1111-1111-1111-111111111111",
    "phone": "+919876543210"
  }'
Response: You will receive a 201 Created with a JWT accessToken:

json


{
  "success": true,
  "data": {
    "accessToken": "eyJhbGciOi...",
    "tokenType": "Bearer",
    "email": "devotee@iskcon.org",
    "userId": "...",
    "roles": ["DEVOTEE"]
  }
}
3. Log in (to get an access token)
powershell


curl -X POST http://localhost:8080/api/v1/auth/login `
  -H "Content-Type: application/json" `
  -d '{
    "email": "devotee@iskcon.org",
    "password": "Password@123"
  }'
4. Access Protected Profile (/me)
Copy the accessToken from the login response and call:

powershell


$TOKEN="<paste_token_here>"
curl -X GET http://localhost:8080/api/v1/users/me `
  -H "Authorization: Bearer $TOKEN"
You will get the authenticated user profile along with role and permission sets.

5. Create a Devotee Profile
powershell


curl -X POST http://localhost:8080/api/v1/devotees `
  -H "Authorization: Bearer $TOKEN" `
  -H "Content-Type: application/json" `
  -d '{
    "userId": "<paste_user_id>",
    "centreId": "11111111-1111-1111-1111-111111111111",
    "legalName": "Rahul Sharma",
    "profileType": "STUDENT",
    "phone": "+919876543210",
    "city": "Pune"
  }'
6. Add Student Sub-Profile
powershell


curl -X PUT http://localhost:8080/api/v1/devotees/<devotee_id>/student-profile `
  -H "Authorization: Bearer $TOKEN" `
  -H "Content-Type: application/json" `
  -d '{
    "institution": "COEP Pune",
    "course": "B.Tech Computer Engineering",
    "yearOfStudy": 3,
    "hostelResident": true
  }'
7. Test Logout (Redis Token Blacklisting)
powershell


curl -X POST http://localhost:8080/api/v1/auth/logout `
  -H "Authorization: Bearer $TOKEN"
After this, any subsequent requests with that same token will be rejected immediately with 401 Unauthorized.
